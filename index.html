/ 02 — возможности

Маленькое приложение, которое делает одно дело хорошо.

01

Полный список форматов

yt-dlp вытягивает все доступные потоки видео и аудио для конкретной ссылки — ничего не скрыто.

02

Автослияние в MP4

Высокие разрешения на YouTube отдаются отдельно от аудио — приложение сливает их через ffmpeg без лишних действий.

03

Прогресс в реальном времени

Процент, скорость и ETA во время загрузки; интерфейс не подвисает — скачивание идёт в отдельном потоке.

04

Portable .exe

Один файл, без установки. Скачал — запустил.

05

Открытый код

Python + tkinter + yt-dlp. Можно собрать самому через PyInstaller за одну команду.

06

Понятные ошибки

Приватное видео, недоступный регион, отсутствие ffmpeg, папка без прав — сообщение объясняет причину.

/ 03 — установка

Запусти за минуту.

Скачай YouTubeDownloader.exe

Из раздела Releases репозитория — файл ничего не устанавливает, просто запускается.

Поставь ffmpeg (для качества выше 720p)

winget install Gyan.FFmpeg — либо положи ffmpeg.exe рядом с программой.

Вставь ссылку и нажми «Get info»

Появится список качеств — выбери нужное и укажи папку для сохранения.

Нажми «Download»

Прогресс-бар покажет процент, скорость и ETA. По завершении — путь к готовому файлу.

/ 04 — ограничения

Честно о том, чего пока нет.

Без плейлистов

Скачивается только одно видео по ссылке — режим плейлиста отключён намеренно.

Без субтитров и очереди

Один файл за раз, без автообновления и фоновой очереди загрузок.
